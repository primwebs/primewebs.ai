# Prime Webs CRM

A standalone, mobile-first lead calling queue and callback calendar.

## Features
- Add leads with business name, email and phone number.
- Calling queue with click-to-call (`tel:`), Next, and remove-not-interested.
- Schedule callbacks from the calendar or directly from the calling screen.
- Data persists in the current browser using localStorage.

## Deploy
This is a static site. Connect the repository to Vercel and deploy from the `main` branch. No external database or API keys are required for this first version.

## Important data note
Leads and callbacks are stored locally in the browser/device used. They are not synchronized across devices yet.
