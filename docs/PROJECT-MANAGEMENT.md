# Project management

The dashboard and project list support renaming a website without changing its content.

- Select **Omdøb** next to a project.
- Enter a name up to 80 characters and select **Gem**.
- Use **Annuller** to exit without saving.
- The project timestamp updates after a successful rename.

Renaming only changes the project's display name in the existing project store. It does not change a configured domain, publish status, customer records, or website content.
